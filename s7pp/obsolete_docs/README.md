# Obsolete / Archived Docs

This directory contains documents that are kept for historical traceability but are not part of the active reference set.

Use the active indexes first:

- `README.md`
- `ai_impl_docs/DOCUMENT_INDEX.md`

## Archive layout

### `obsolete_docs/oscilloscope/`
Top-level oscilloscope milestone summaries, quick references, and integration snapshots.

### `obsolete_docs/shape_aware/`
Top-level shape-aware-node milestone and summary docs.

### `obsolete_docs/ui/`
Older sidebar/UI redesign docs that are no longer the primary reference.

### `obsolete_docs/milestones/`
Generic project/milestone summaries and day-by-day accomplishment logs.

### `obsolete_docs/ai_impl/oscilloscope/`
Historical AI implementation handoff notes for the oscilloscope workstream.

### `obsolete_docs/ai_impl/milestones/`
Historical AI implementation summaries and session notes.

### `obsolete_docs/ai_impl/runtime/`
Deprecated runtime and I/O design snapshots superseded by current docs.

## Rule of thumb

If a document describes the current architecture, behavior, or contract, it should live outside `obsolete_docs/` and be linked from the main indexes.
If it is a milestone snapshot, handoff note, temporary summary, or superseded design writeup, it belongs here.
