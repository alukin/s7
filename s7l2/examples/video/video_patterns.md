# Video Player test patterns

Open `video_patterns.s7diagram` in Studio. Run at 25 Hz for 0.24 s,
then open either Video Player. Each receives a 5 × 3 checkerboard with
a moving marker. The RGB marker is red and the grayscale marker is white.

Use **Print… → Save as PDF…** in the viewer to save the displayed frame
with its source sequence, committed step and pixel geometry.
